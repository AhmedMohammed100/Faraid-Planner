# Faraid Planner

## Islamic Estate & Inheritance Planning System

Faraid Planner is a blueprint-first web application for organising Islamic inheritance cases.

The purpose of the system is not simply to calculate monetary inheritance amounts.

Instead, it separates an inheritance case into:

1. Estate identification
2. Ownership verification
3. Debts and obligations
4. Wasiyyah
5. Surviving heirs
6. Faraid entitlement
7. Property allocation
8. Family settlement
9. Professional review
10. Legal completion

---

# Core Principle

## Entitlement is not the same as property.

Islamic inheritance establishes an heir's entitlement to the estate.

The estate itself may contain:

- Houses
- Land
- Farms
- Vehicles
- Businesses
- Bank accounts
- Gold
- Investments
- Livestock
- Other property

The application therefore does not require every asset to have an immediate cash value.

A house can be recorded as:

> Family house — valuation pending.

The inheritance framework can still be established while the valuation and property settlement are handled separately.
